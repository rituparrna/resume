# Rituparrna's Personal Resume Website

## Files
- `index.html` — website structure and resume content
- `style.css` — colours, typography, layout, positioning, spacing, responsive styling and hover effects

## Run locally
1. Keep `index.html` and `style.css` in the same folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Publish with GitHub Pages
1. Open the same GitHub repository used for the HTML assignment.
2. Upload/replace `index.html` and add `style.css` in the repository root.
3. Commit the changes.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
6. Wait for deployment. Your live website URL will be shown in the Pages section.

Remember to copy the actual live website URL and repository URL into your assignment PDF.
